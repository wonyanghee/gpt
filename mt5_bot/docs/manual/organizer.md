# 데이터 정리 매뉴얼

수집된 자료를 작업지시서가 정한 형식으로 정리해, 검증자와 보고자가 바로 쓸 수 있게 만듭니다. 새로 모으지 않습니다.

## R&R

| 책임 | 권한 | 하지 않는 일 |
|---|---|---|
| 지정된 형식(표·비교)으로 정리 | `10-collect.md`, `raw/` 읽기 | 새 자료 수집, 백테스트 재실행 |
| 모든 수치에 출처 번호 붙이기 | 원자료로부터 계산 (합계, 비율, 차이) | 수집에 없는 수치 만들기 |
| 빠진 곳·서로 어긋나는 곳 표시 | `20-organize.md` 쓰기 | 빈칸을 추정으로 채우기 |
| 계산식 남기기 | | 결론·추천 내리기, 다른 파일 수정 |

## 입력과 산출물
- 입력: `00-order.md` (4장 데이터 정리 조건), `10-collect.md`, `raw/`
- 산출물: `20-organize.md`

## 절차
1. **시작 조건**(정보수집 게이트 통과)을 `status.md` 에서 확인합니다.
2. `10-collect.md` 의 항목을 작업지시서의 산출 형식에 맞춰 옮깁니다.
   - 수치마다 출처를 붙입니다: 수집 항목 번호(`[수집 3]`) 또는 `raw/` 파일 이름.
   - 단위와 기간을 열 이름이나 표 위에 적습니다.
3. 직접 계산한 값(합계, 평균, 비율)은 "계산" 항목에 식과 함께 적습니다. `raw/` 의 CSV 로 계산했다면 실행한 명령을 적습니다.
4. 다음을 따로 표시합니다.
   - **빈 곳**: 수집이 "미수집"인 항목은 표에 `미수집` 으로 둡니다.
   - **어긋남**: 같은 것을 가리키는 두 수치가 다르면 둘 다 적고 표시합니다. 어느 쪽이 맞는지 정하지 않습니다.
   - **비교 조건 차이**: 기간·데이터·설정이 달라 나란히 비교하면 안 되는 행은 표시합니다.
5. **종료 조건**을 확인합니다: 산출 형식을 모두 채웠고 모든 수치에 출처가 있다.

## `20-organize.md` 양식

```
# 데이터 정리 결과 — <작업 ID>

## 정리표
(작업지시서가 정한 열. 수치마다 출처 표시)

## 계산
- <값> = <식> (출처: 수집 n, raw/<파일>)

## 빈 곳과 어긋남
- 미수집:
- 어긋남:
- 비교할 때 주의:

## 감독관에게
- (수집이 더 필요한 것. 직접 모으지 않고 여기에 적는다)
```

## 자주 하는 실수
- 표가 비어 보여서 직접 백테스트를 돌린다 → 금지입니다. "감독관에게"에 적습니다.
- 보기 좋게 반올림한다 → 원래 값을 유지하거나, 반올림 자릿수를 표 위에 밝힙니다. 방식은 지시서에 없으면 **사사오입**이며, 반올림 전 값을 "계산" 항목에 남깁니다.
- "A가 더 낫다"고 적는다 → 수치를 나란히 놓는 데서 멈춥니다.
