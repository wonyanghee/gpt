# 작업지시서 — 데모 거래 기록 성과 정리 (시범 운영)

- 유형: 운영 분석

## 1. 요청 원문
새 단계별 에이전트 팀이 끝까지 돌아가는지 확인하기 위한 시범 작업. 데모 실행(`python run_demo.py`, 기본 시드 42, 20거래일)의
거래 기록을 종목별·청산 유형별로 정리한다. 가상 시세이므로 전략 성능 평가가 목적이 아니다.

## 2. 완료 기준
- [ ] 데모 거래 기록에서 종목별 청산 건수, 승률, 손익 합계를 답한다.
- [ ] 청산 유형(반대 신호 청산 `close` / 비상 손절 `stop`)별 건수와 손익 합계를 답한다.
- [ ] 위 수치가 `run_demo.py` 가 화면에 출력한 요약(거래수, 비상손절 건수, 종목별 건수·손익)과 일치하는지 답한다.
- [ ] 거래 기록 파일에서 분석에 방해가 되는 점(열 의미가 불분명하거나 빠진 정보)이 있으면 적는다.

## 3. 정보수집 조건
- 시작 조건: `mt5_bot/logs/demo_trades.csv` 가 있다.
- 범위: 이 파일과, `python run_demo.py --quiet` 를 한 번 다시 실행한 출력. 그 밖의 자료는 범위 밖이다.
- 허용 출처: 거래 기록 파일 / 데모 실행 출력. 웹과 백테스트는 쓰지 않는다.
- 필수 수집 항목:
  1. `demo_trades.csv` 의 열 이름과 전체 행 수, `action` 값별 행 수
  2. 종목(`symbol`)별: 청산 행(`action` 이 `close` 또는 `stop`) 수, 그중 `profit` 이 0보다 큰 행 수, `profit` 합계
  3. 청산 유형(`close` / `stop`)별: 행 수, `profit` 합계
  4. `python run_demo.py --quiet` 출력 전문 (원자료로 저장)
  5. 거래 기록의 `time` 열 값 범위(최소·최대)와, 데모 출력에 나오는 시뮬레이션 날짜 범위
- 종료 조건: 필수 항목 5개를 모두 채웠거나 한도에 닿았을 때. 못 채운 항목은 "미수집 + 사유"로 남긴다.
- 한도: 데모 실행 최대 1회. 그 밖의 명령은 읽기·집계용만.
- 주의: `run_demo.py` 를 실행하면 `logs/demo_trades.csv` 가 새로 쓰인다. 항목 4를 먼저 실행한 뒤 그 파일을 `raw/` 로 복사해 집계한다.

## 4. 데이터 정리 조건
- 시작 조건: 정보수집 게이트 통과
- 산출 형식:
  - 표 1 (종목별): 종목 / 청산 건수 / 수익 건수 / 승률(%) / 손익 합계
  - 표 2 (청산 유형별): 유형 / 건수 / 손익 합계
  - 표 3 (대조): 항목 / 거래 기록에서 집계한 값 / 데모 출력 값 / 일치 여부
  - 손익은 소수 둘째 자리, 승률은 소수 첫째 자리.
- 종료 조건: 표 3개를 모두 채웠고 모든 수치에 출처(수집 항목 번호)가 붙어 있다.
