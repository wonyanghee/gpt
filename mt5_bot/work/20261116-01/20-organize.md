## 계산

수집 값은 `10-collect.md` 에 반올림 없이 적힌 값이다. 반올림은 사사오입(ROUND_HALF_UP)으로 했고, 아래 값들은 은행가 반올림(ROUND_HALF_EVEN)으로 해도 결과가 같다.

1. US100 승률 30.6 = 19 ÷ 62 × 100 = 30.6451… (출처: 수집 2)
2. XAUUSD 승률 32.1 = 17 ÷ 53 × 100 = 32.0754… (출처: 수집 2)
3. 종목별 손익 반올림 (출처: 수집 2, `raw/aggregate.out.txt`)
   - US100: -1202.390800000015389 → -1202.39
   - XAUUSD: -558.6400000001208186 → -558.64
4. 청산 유형별 손익 반올림 (출처: 수집 3, `raw/aggregate.out.txt`)
   - `close`: 629.9126999998662724 → 629.91
   - `stop`: -2390.94350000000248 → -2390.94
5. 맞춤 확인 (새 수치가 아니라 수집 값끼리의 합 확인)
   - 건수: 62 + 53 = 115 (수집 2), 88 + 27 = 115 (수집 3) → 같다.
   - 반올림 전 손익: 종목 합 -1202.390800000015389 + -558.6400000001208186 = -1761.0308000001362076,
     유형 합 629.9126999998662724 + -2390.94350000000248 = -1761.0308000001362076 → 같다. 수집 2의 전체 합계와도 같다.
   - 반올림 후 손익: -1202.39 + -558.64 = -1761.03, 629.91 + -2390.94 = -1761.03 → 같다.

재계산에 쓴 명령 (`raw/demo_trades.csv` 를 읽기만 했다. `raw/` 에 파일을 만들지 않았다):

```
cd mt5_bot/work/20261116-01/raw && python3 -I - <<'EOF'
import csv
from decimal import Decimal, ROUND_HALF_UP
rows = list(csv.DictReader(open('demo_trades.csv', encoding='utf-8-sig')))
ex = [r for r in rows if r['action'] in ('close', 'stop')]
for key in ('symbol', 'action'):
    for v in sorted({r[key] for r in ex}):
        s = [r for r in ex if r[key] == v]
        n = len(s); w = sum(Decimal(r['profit']) > 0 for r in s)
        tot = sum(Decimal(r['profit']) for r in s)
        print(key, v, n, w, tot, tot.quantize(Decimal('0.01'), ROUND_HALF_UP),
              (Decimal(w) * 100 / n).quantize(Decimal('0.1'), ROUND_HALF_UP))
EOF
```

- 이 명령의 결과(건수, 수익 건수, 반올림 전 합계)는 [수집 2]·[수집 3] 의 값과 모두 같았다.
- 같은 명령에서 나온 유형별 수익 건수(`close` 36, `stop` 0)는 표 2 의 지정 열이 아니라 표에 넣지 않았다.
